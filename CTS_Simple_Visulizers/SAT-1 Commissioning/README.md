# SAT-1 Commissioning

Browser walk-through of the 18 CubeADCS commissioning steps (CubeSpace Commissioning Manual V7.1, Table 1) for CTS SAT-1. Each step plays back what the satellite does, the live telemetry curves, the command sequence, what to log, how to tell it worked, and what to do if it didn't.

No install. Open `index.html` in a browser, or serve this folder (`python -m http.server`). On GitHub Pages it lives at `/SAT-1%20Commissioning/`.

- Arrow keys move between steps, space plays or pauses, and command rows are clickable to jump in time.
- Calculators: inertia ratio (step 3), Y-wheel test speed (7), gyro bias (15), ground target reference (17).
- Curves are schematic, shaped from the manual's figures and text. They are not flight data.
